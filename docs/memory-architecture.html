这张图证明了什么

  • 路径是真的：启动真实 dsh profile 后 find 出来的 —— 会话在 sessions/<projectKey(cwd)>/<id>/， 生命在 life/<lifeId>/。两者分桶方式不同，这正是跨对话的根据。
  • 数字是量的：690B 是灌入 200 兴趣 + 200 承诺后的实测快照； 截断降级、账本震荡区间都跑过。
  • 机制有断言：注入点、布防时机、原子写、快照有界， 在 verify/smoke.mjs、verify/life-week.mjs、verify/publish.mjs 里有对应检查。

这张图没有证明什么

  • 长期记忆会不会「糊」：跑三个月要不要总结、怎么总结，未验证。
  • 跨进程没有锁：dsh 有 session.lock，我们这层没有。
  • 真实长跑没做过：七天是压缩跑的，没有真实等待，也没跨真实进程重启。
  • 发布线一次真实发送都没有过：状态机有断言，平台是真没连过。
