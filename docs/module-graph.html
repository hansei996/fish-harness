这张图证明什么

  • 依赖是单向的、没有环：index → 领域模块 → 共享底层。 四个纯函数模块（choose / wake / compliance / config）不 import 任何 IO， 所以能脱离 dsh 单独跑 —— 七天长跑就是靠这个压成 0.1 秒。
  • 只有一个装配点：全部接线收在 index.js， 其他八个模块不知道 dsh 的存在。换底座只改一个文件。
  • 没有循环依赖：store → outbox → compliance、 store → wake、ui → wake，方向一致。

这张图没有证明什么

  • 不代表模块划分是唯一正确的：outbox 849 行偏大， 以后可能要拆（发布 vs 对账）。
  • 客户端不在这张图里：client/life-overview.js（176 行） 跑在浏览器半身，与这九个模块不共享内存。
  • 真实长跑没做过：模块边界在七天压缩跑里成立，不等于在真实进程重启下成立。
