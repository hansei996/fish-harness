这一张图从上往下是一条完整的链：dsh 自带什么 → 我们挂在它的哪些扩展点上 → 生命层的九个模块谁 import 谁、各自管什么 → 这些模块往磁盘上写什么。 线全部是真的：模块之间的实线扫自源码的 import，指向 dsh 的虚线取自真实的公开 API 调用， 指向磁盘的线取自 writeJsonAtomic 的调用点。数字由 node tools/facts.mjs 量出，不手抄。

Band 1 · 底座（deepsseek harness，不是我们写的）

dsh 是「一切皆插件」的运行时：一次干净安装里有 306 个 @deepseek-ai/* 包 （去重后的包名个数；.pnpm 下共 560 个目录，同一个包会因 peer 组合占多个）。 数法：ls node_modules/.pnpm | grep -o '^@deepseek-ai+[a-z0-9.-]*' | sort -u | wc -l， 装的是 dsh 0.2.1-rc.2。下面三组是与我们相关的： 青色框是 dsh 自己就有的「连续性」组件（会话落盘、上下文压缩、持久目标、跨会话引用）， 蓝色框是我们真正挂上去的扩展点。

Band 4 · 磁盘（实跑 dsh 之后 find 出来的）

两边落在不同的键下，这就是「换目录、换会话，它还是同一个它」的根据： dsh 按 projectKey(cwd) 分会话，我们按 lifeId 分生命。

dsh 管什么 · 会话世界

  • 一次对话之内的一切：轮次、工具、沙箱、批准、提示词装配。
  • 会话的持久化：每会话一个 JSONL，含尾部截断恢复。但是 —— 状态挂在这条会话上。
  • 上下文不会爆：快满时把最老的历史压成摘要。
  • 一个会话一个目标：dsh-goal 跨轮次、跨 resume、跨重启。
  • 跨会话看别人：dsh-session-reference 把别的会话摘成只读快照当背景。
  • 它没有的：一个跨会话仍然成立的「我」；也没有「没人叫、自己醒」—— schedule 只是个定时器，没有抖动、没有免打扰、没有每日预算（全包搜这三个词 0 命中）。
交界

我们补什么 · 生命世界

  • 键从会话换成生命：life/<lifeId>/。会话没了，命还在 —— 换 cwd、换会话、进程重启，它还是同一个它。
  • 状态按变化速度分层：极慢（身份，改要主人确认）/ 慢（兴趣、关系、承诺）/ 快（当前活动、闹钟）/ 只追加（账本）。
  • 每轮只付固定的一小笔：注入 13 个字段，实测 648 字节封顶（灌满 200 个兴趣 + 200 条承诺之后量的，实际各取前 5 / 5 条）。不随寿命增长 —— 这是长期跑得起的关键取舍：不是记得越多越好，而是每轮只付固定的一小笔。
  • 自己会醒：在 dsh 的定时器上补三样它没有的 —— 抖动、静默时段、每日预算， 并按 messageId 幂等记账。
  • 明天接着昨天：每轮结束留一条 next，下一次醒来在快照里读得到。 （这条曾是死代码，是七天连跑把它暴露出来的。）
  • 外部副作用单独管：sending 先落盘再发； unconfirmed 没有自动重试路径。

这张图证明什么

  • 接线全是公开扩展点：五个服务注入（tools · systemPrompt · schedule · approval · webServer）加两个事件监听 （session/event · agent/inbox/claimed），再加客户端两个 slot。 没有一处改 dsh 核心，所以 dsh 升级不会把我们改坏。
  • 模块之间的线是真的：9 个模块的 11 条 import 扫自源码， 四个纯函数模块（choose / wake / compliance / config）不 import 任何 IO —— 七天长跑能压成 0.1 秒就是靠这个。
  • 写盘只有一个口：8 个状态文件的每一次写入都经过 store.js 的 writeJsonAtomic（tmp + rename）。入口和发布线只调 store，不自己写文件。
  • 两地分键是有意的：dsh 按 projectKey(cwd)，我们按 lifeId —— 这才是「会话会结束，命不会」的机制，而不是一个说法。

这张图没有证明什么

  • 长期记忆会不会「糊」：跑三个月要不要总结、怎么总结，未验证。
  • 我们这层没有跨进程锁：dsh-atomic-write 有 withFileLock， 我们没引它 —— 并发读改写只靠「每次重读」，真双进程压测会看到丢更新。
  • 真实长跑没做过：七天是压缩跑的（没有真实等待），也没有跨真实进程重启。
  • 发布线一次真实发送都没有过：状态机与标识硬闸有断言，平台是真没连过。
  • UI 只有只读接口：/life/state.json 有测试，像素级没有。
